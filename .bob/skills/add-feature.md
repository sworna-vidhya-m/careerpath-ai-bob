# Skill: Add Feature to CareerPath AI

When asked to add a new feature, follow these steps in order:

1. Read README.md and README_CHECKLIST.md to confirm current app flow.
2. Identify the layer the change belongs to: UI (frontend), API (backend
   route), data model, or AI prompt/agent logic.
3. Check 1-2 existing similar features and reuse their patterns. Do not
   introduce new libraries unless absolutely necessary.
4. For any new endpoint, add input validation and error handling.
5. For any new UI component, follow the existing component style.
6. After implementation:
   - Add or update relevant tests
   - Update README.md if user-facing
   - List the files changed in your final summary

Constraints:
- Do not modify .env or any credential files
- Do not add tracking or analytics
- Keep changes minimal and focused on the requested feature
