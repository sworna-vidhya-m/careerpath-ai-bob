## Architecture Decisions
- **Two-venv separation**: Python 3.9 for FastAPI (stable, production-ready) vs Python 3.13 for MCP (latest features). Keeps dependencies isolated and allows independent upgrades.
- **HTTP-based MCP**: MCP server calls FastAPI over HTTP rather than direct imports. Enables true separation of concerns, easier testing, and potential for distributed deployment.
- **Pagination as project rule**: Codified in .bob/rules/pagination-rule.md to ensure consistent UX across all list views. Prevents ad-hoc implementations and maintains 10-records-per-page standard.
