## Problem statement

- Enterprises lack a single view of who can do what, who is on the bench, and where skill gaps exist — managers rely on spreadsheets and quarterly surveys that are obsolete before they are read.
- Idle bench employees burn OPEX, attrition rises when career paths are invisible, project staffing delays compound, and workforce skills chronically lag industry demand in fast-moving areas like GenAI, MLOps, and cloud-native architecture.
- The opportunity: one platform that maps every employee, their skill proficiencies, their projects and assignments, their manager chain, and the skills their business unit needs next — turning scattered data into actionable staffing and career decisions.
- IBM Bob makes it buildable in a hackathon window: the development team provides the structured domain API; Bob adds the analytical reasoning layer on top.

---

## Solution

CareerPath AI is a FastAPI application backed by SQLite, served alongside a self-contained vanilla JavaScript dashboard. The backend exposes 11 normalized entities covering employees, business units, projects, assignments, skills, career paths, and learning resources — with full CRUD, pagination, and entity-specific filters on every endpoint. The enterprise-styled dashboard provides create, edit, and delete workflows on four operational tabs with 10-records-per-page pagination.

IBM Bob extends the platform during the hackathon by implementing five intelligent analytics endpoints: skill-gap analysis per employee, AI-assisted career path recommendations, bench-to-learning auto-enrollment, an industry-trend skill recommender per business unit, and the skill heatmap aggregation that feeds the fifth dashboard tab — the Skill Matrix.

## Tech stack

* Backend: Python 3.11+, FastAPI, Pydantic v2
* ORM: SQLAlchemy 2.0
* Database: SQLite (`data/app.db`)
* Frontend: Vanilla JavaScript, embedded CSS, single HTML file
* Testing: pytest, FastAPI TestClient, in-memory SQLite
* AI: IBM Bob IDE
* Version control: GitHub

## Modules

### Employees module (`app/routers/employees.py`)

Manages the full employee lifecycle across all business units.

* List with filters: `business_unit_id`, `status`, `band`
* Get / create / update / delete
* Self-referential `line_manager_id` supported

### Projects and assignments (`app/routers/projects.py`, `assignments.py`)

Tracks client and internal projects alongside staff allocations.

* Project lifecycle status: ACTIVE / COMPLETED / ON_HOLD
* Assignment with `allocation_pct` and `active_only` filter

### Skills and employee skills (`app/routers/skills.py`, `employee_skills.py`)

Central skill taxonomy linked to individual proficiency records.

* Skill categories: TECHNICAL, DOMAIN, SOFT, plus `is_emerging` flag
* EmployeeSkill proficiency 1–5 with `last_used_at` and `certified` flag

### Industry-standard skills (`app/routers/industry_standards.py`)

Tracks market-level skill demand per business unit.

* Per-BU skill importance (1–5) and trend: RISING / STABLE / DECLINING

### Career paths (`app/routers/career_paths.py`, `career_path_requirements.py`)

Defines structured role-progression tracks within a business unit.

* From-role to-role progressions scoped to a business unit
* Required skills with `min_proficiency` thresholds

### Learning (`app/routers/learning_resources.py`, `enrollments.py`)

Catalog of learning resources and employee enrollment tracking.

* Resource types: COURSE / CERTIFICATION / BOOK / WORKSHOP
* Enrollment status: ENROLLED / IN_PROGRESS / COMPLETED / DROPPED

### Analytics (`app/routers/analytics.py`) — reserved for IBM Bob

* `GET /analytics/skill-gap/{employee_id}`
* `GET /analytics/career-recommendations/{employee_id}`
* `POST /analytics/trigger-bench-learning`
* `GET /analytics/industry-trends/{business_unit_id}`
* `GET /analytics/skill-heatmap`

### Sample seeded data

* 30 employees across 8 business units (20 ACTIVE, 6 BENCH, 4 LEARNING)
* 62 skills (30 technical, 12 emerging, 10 domain, 10 soft)
* 20 projects (14 active, 6 completed)
* 12 career paths and 53 required-skill thresholds
* 60 learning resources, 15 active enrollments
* Deterministic seed (`random.seed(42)`) — stable across runs

## How to run locally

```bash
# Clone the repository
git clone https://github.com/<your-username>/careerpath-ai-bob.git
cd careerpath-ai-bob

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the application
./run.sh
# OR
uvicorn app.main:app --reload

# Open browser
# http://localhost:8000
```

## IBM Bob integration

IBM Bob is used during the hackathon to implement the intelligent analytics layer on top of the pre-built domain API.

| Bob feature | How used |
|---|---|
| `/init` | Generates `AGENTS.md` with project context |
| Plan mode | Designs skill-gap algorithm and career recommendation logic |
| Code mode | Implements analytics endpoints, tests, and Skill Matrix UI wiring |
| Literate coding | Wires the Skill Matrix heatmap tab from natural-language directives |
| `/review` | Catches issues across the codebase before final commit |
| Commit messages | Generates descriptive commit messages from staged diffs |
| Pull requests | Generates PR descriptions for the analytics-layer changes |

All Bob task session reports are saved in the `bob_sessions/` folder.
